# ADR-001: Use Nuxt as Frontend Framework

## Status

Accepted

## Context

The portfolio targets a global audience and requires strong SEO,
performance, accessibility, and interactive functionality.

## Decision

Use Nuxt 4 with Vue 3 and TypeScript.

## Reasons

- Server-side rendering
- SEO support
- Hybrid rendering
- Vue ecosystem
- Good developer experience
- Image optimization
- Route-level metadata
- Strong performance capabilities

## Consequences

The frontend is more structured than a simple Vue SPA,
but provides better SEO and production capabilities.
